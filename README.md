# 🛒 Blinkit Sales Analysis Dashboard

## 📊 Project Overview

This project is an interactive **Blinkit Sales Analysis Dashboard** created using **Microsoft Power BI**.

The dashboard analyzes sales, outlet performance, item types, fat content, outlet size, outlet location, ratings, and item visibility.

## 🛠️ Tools Used

- Microsoft Power BI
- Power Query
- DAX
- Data Cleaning
- Data Visualization

## 🎯 Objectives

- Analyze total sales
- Analyze outlet performance
- Compare outlet types
- Compare outlet locations
- Analyze item types
- Analyze fat content
- Analyze outlet ratings
- Identify high-performing outlets

## 📌 Key KPIs

| KPI | Value |
|---|---:|
| Average Rating | 3.9 |
| Average Sales | 141 |
| Total Sales | $1.20M |
| Number of Items | 8,523 |

## 🔍 Key Insights

- Total sales are approximately **$1.20M**.
- Average rating is **3.9**.
- Total number of items is **8,523**.
- Supermarket Type 1 has the highest total sales.
- Tier 3 outlets have the highest sales among the location tiers.
- Fruits & Vegetables and Snack Foods are among the highest item categories.
- Sales vary significantly based on outlet establishment year.
